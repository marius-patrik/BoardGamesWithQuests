# Goal

Ship a publicly playable, secure, accessible board-game platform with quests. Generic, deterministic Python JSON rule execution powers chess, English and international draughts and last an original 2–8-player MoneyProperty economy. Supabase/FastAPI own persistent identity and state; one React client also runs in a Tauri shell.

Completion requires full browser authoring, replay/recovery, provider-backed security/concurrency, correct deployed web/API/docs/native builds and 30 participants across 15 games sharing a classroom IP. The full definition of done is in [master #348](https://github.com/marius-patrik/BoardGamesWithQuests/issues/348).
