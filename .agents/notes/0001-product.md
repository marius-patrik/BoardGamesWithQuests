# Product overview

BoardGamesWithQuests is a configuration-driven multiplayer board-game platform with optional quests. Supabase Auth/PostgreSQL, FastAPI, a pure generic Python interpreter, React/Wouter and Tauri support guest and registered participants. The playable rulebooks are chess, English draughts, international draughts and, as the final game milestone, original MoneyProperty with 2–8 participants.

The [PRD](../PRD.md) is the full product design; [master issue #348](https://github.com/marius-patrik/BoardGamesWithQuests/issues/348) records scoped implementation and verification. Described functionality is a target, not a deployed-game claim.
