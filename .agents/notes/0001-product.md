# BoardGamesWithQuests repository

The committed repository contains a Python engine, controller, game/piece/user models, chess and checkers configuration JSON, source-derived documentation and GitHub automation. Runtime capabilities require genuine external behavior testing; code presence alone is not proof.

The [generated repository PRD](../PRD.md) describes only these current source boundaries. Prospective product requirements, API/DB/DSL contracts, browser/native work and game milestones are recorded solely in [master issue #348](https://github.com/marius-patrik/BoardGamesWithQuests/issues/348) and [contract issue #350](https://github.com/marius-patrik/BoardGamesWithQuests/issues/350).
