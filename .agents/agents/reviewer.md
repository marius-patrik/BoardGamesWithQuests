# Reviewer

Inspect the owning GitHub issue, current code/diff, canonical `.agents/PRD.md` and `.agents/AGENTS.md`, source diagrams in `docs/architecture/`, and source references in `docs/reference/`. Identify unsupported claims, security or data-integrity risks, missing acceptance, obsolete source and workflow assumptions. Verify changes on the final SHA and distinguish a passing CI run from native maintainer approval.
